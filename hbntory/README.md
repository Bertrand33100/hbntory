# HBntory — Inventory Management Platform

Projet Holberton School — Bertrand Oeung, Thomas Corbel.

## Structure du dépôt

| Dossier | Contenu |
| --- | --- |
| `backoffice/` | Application interne : utilisateurs, stock par agence (REST + HTML/CSS/JS) |
| `ai_service/` | AI Query Service : agent IA qui répond aux questions des clients |
| `mcp_server/` | Serveur MCP : outils produits (Product API) et stock (base de données) |
| `client_web/` | Page publique de questions en langage naturel |
| `docs/` | Architecture, décisions, MVP, diagramme |
